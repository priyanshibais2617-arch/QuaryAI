3. DOMAIN 2: AI AGENTIC ORCHESTRATION & SPECIALIST REASONING
================================================================================
STATUS: 95% COMPLETED (Deterministic Agent Prototype per specifications)

WHAT HAS BEEN IMPLEMENTED:
- Input Analyzer (src/ai/inputAnalyzer.js):
  * Inspects staged rasters: count (1 vs 2), modality extraction (Optical, SAR,
    Multispectral), temporal pairing detection, cross-modal pairing detection.
  * Emits input metrics, resolution parity flags, and validation issues.
- Query Classifier (src/ai/queryClassifier.js):
  * Deterministic semantic pattern and intent classifier covering:
    1. Single Image VQA ("describe land cover", "what objects", "vegetation percentage")
    2. Visual Grounding ("where is", "locate", "pinpoint", "bounding box")
    3. Scene Captioning ("describe scene", "generate caption", "summarize")
    4. Bi-Temporal Change Analysis ("what changed", "before and after", "expansion")
    5. Change VQA ("has built-up area increased", "did water bodies change")
    6. Optical-SAR Cross-Modal Fusion ("combine optical and sar", "both images")
    7. General Remote Sensing Query (graceful guidance)
- Workflow Router (src/ai/workflowRouter.js):
  * Validates query against input metadata.
  * Wrong-workflow prevention: Flags missing 2nd image for bi-temporal query,
    flags missing SAR raster for optical+SAR query, prevents misrouting 2 optical
    images into optical-sar.
  * Selects specialist engine and produces deterministic routing rationale.
- Main Agent Controller (src/ai/mockAgent.js):
  * End-to-end autonomous controller executing the active specialist engine.
  * Produces comprehensive 10-step timestamped execution trace:
    Step 1 : Input Received & Metadata Ingested
    Step 2 : Multi-Band & Modality Validation
    Step 3 : Natural Language Query Parsing & Semantic Parsing
    Step 4 : Task Classification & Intent Identification
    Step 5 : Agentic Workflow Routing & Precondition Verification
    Step 6 : Specialist Engine Selection
    Step 7 : Specialist Model Execution & Feature Extraction
    Step 8 : Visual Evidence & Spatial Localization Synthesis
    Step 9 : Uncertainty Calibration & Prototype Confidence Metric
    Step 10: Result Aggregation & Unified Contract Delivery
- Unified Result Integrator (src/ai/resultIntegrator.js):
  * Normalizes all specialist outputs into a unified data contract:
    { task, workflow, specialist, answer, confidence, evidence, summaryCards,
      executionTrace, prototype: true }
- 6 Registered Specialist Engines (src/ai/mockSpecialists/):
  1. mockVQA.js: Land cover breakdown (Urban, Scrubland, Water, Trees), spectral attributes.
  2. mockGrounding.js: Pixel-aligned spatial coordinates & bounding box [x, y, w, h].
  3. mockCaptioning.js: Multi-sentence natural scene description with categorical tokens.
  4. mockChange.js: Anthropogenic expansion metrics, 4 change clusters, affected sector.
  5. mockChangeVQA.js: Targeted direct affirmative/negative change answers.
  6. mockOpticalSAR.js: Fused optical spectral absorption + SAR microwave backscatter,
     double-bounce radar returns, 100% cloud occlusion penetration.
- Model Registry & Domain Adaptation Representation (src/data/mockModelRegistry.js):
  * Complete registry of the 6 specialist engines with simulated parameter counts.
  * Visual representation of BigEarthNet / Open RS pretraining and fine-tuning pipeline.

WHAT IS NEEDED IN THIS DOMAIN:
- Actual PyTorch / ONNX / TensorRT runtime for true deep learning inference.
- Integration with real open-source Geospatial Foundation Models:
  * GeoChat / EarthGPT for Remote Sensing Vision-Language Q&A.
  * RemoteCLIP for multi-modal text-image alignment.
  * Prithvi (IBM/NASA geospatial foundation model) or SatMAE.
  * Segment Anything Model for Geospatial (SAM-Geo) for zero-shot polygon segmentation.
- Streaming token generator (Server-Sent Events / WebSockets) for real-time LLM reasoning.
- Multi-turn conversational memory (allow follow-up questions on the same raster).
